# Akashic

A study command centre for A level Law (OCR), Philosophy (AQA) and English Language and Literature (AQA), with Zenith: AO blueprints, the phrase forge, sentence craft, the essay forge and the AO radar.

**Open the app:** https://oliainsmith-cmyk.github.io/akashic/

On a Chromebook, open the link in Chrome and choose the install icon in the address bar (or menu, then Cast, save and share, then Install page as app). Once installed it works offline. Your progress is saved in the browser on your device; use Settings in the app to back it up or move it to another device.
